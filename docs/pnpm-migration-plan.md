# pnpm and Node 26 migration

## Objective

Migrate this single-package repository from npm to pnpm, pin pnpm to `12.3.4`, and use Node.js 26 in local metadata, CI, publishing, and documentation.

## Implementation

- Replace `package-lock.json` with a `pnpm-lock.yaml` generated by `pnpm import` without dependency upgrades.
- Add `packageManager: "pnpm@12.3.4"` and change the Node engine to `>=26`.
- Add `.node-version` with `26`; both workflows consume it through `node-version-file`.
- Use `pnpm/action-setup@v6`, frozen installs, pnpm tests, pnpm packaging, and `pnpm publish --provenance`.
- Update repository commands and package-manager references in contributor, README, publishing, planning, and TODO documentation.
- Retain npm registry and Trusted Publishing terminology where it refers to npmjs.org.

## Validation

- Passed under Node 26.8.2 with pnpm 12.3.4: `pnpm install --frozen-lockfile`, `pnpm test` (9/9), and `pnpm run pack:check`.
- Passed `pnpm publish --dry-run --no-git-checks --provenance --registry=https://registry.npmjs.org` without publishing.
- Passed manifest invariants and `git diff --check`.
- Confirmed remaining npm references are registry/package terminology or generic historical portability notes; no stale npm workflow commands or lockfiles remain.

## Done

The pnpm lockfile is committed, the npm lockfile is removed, CI and publishing use Node 26 and pnpm, package tests and packaging checks pass, and only migration-related files are changed. The pre-existing unrelated additions to `docs/TODO.md` were preserved.
